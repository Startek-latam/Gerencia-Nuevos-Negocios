# Gerencia Desarrollo de Negocios y Marca Corporativa

Landing interna de Startek Argentina que consolida los frentes de trabajo de la Gerencia: rol, base de datos, EPC, ELD, propuesta narrativa, puntos de contacto, manual de prospección y próximos pasos.

## Páginas

- `index.html`: landing con tarjetas, status, responsables y tareas
- `rol.html`: resumen ejecutivo del rol
- `epc.html`: Ejecutivo de Prospección Comercial
- `eld.html`: Ejecutivo de Licitaciones y Documentación
- `narrativa.html`: Propuesta Narrativa · Paquete Pyme
- `manual.html`: Manual de Prospección Comercial
- `radar.html`: Agente de Radar · barrido semanal de prospectos
- `presentacion/`: landing de presentación de la Gerencia
- `docs/`: documentos completos en formato web (rol, epc, eld, narrativa, manual) y el Word de la narrativa

HTML estático, sin dependencias. Se publica con GitHub Pages desde la rama `main`.
